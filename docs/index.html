System Security Plan

The System Security Plan (SSP) is a security-controls framework published by the Singapore Government as part of its ICT&SS Policy Reform. It sets out implementable controls tailored to different system characteristics — spanning eight system types, from low-risk cloud deployments up to generative AI systems.

Agencies work from customizable SSP templates organized across three control levels, using them to assess risk and determine the security measures appropriate to a given system's operational context. The result is a common baseline that scales with risk rather than a one-size-fits-all checklist.
